**This is not the product.**

The real project is **[Jolee Remote](https://github.com/Joleeconsultants/joleeremote)** — a public Cloudflare Durable Objects hop for browser↔agent session pairing (mint, pair, opaque frames/input, hibernation, TTL, teardown), using a modified **Selkies UI** as session chrome.

## What this repo is

A personal fork of upstream [selkies-project/selkies](https://github.com/selkies-project/selkies), kept as a **nice-to-have** reference (Selkies dashboard/chrome inspiration for JR).

We are **not** actively developing or shipping from here. Do not open product work against this fork — use `Joleeconsultants/joleeremote` instead.
